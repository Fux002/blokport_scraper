# Optional image-processing extras for the scraped-photo pipeline
# (stone_pipeline/io/image_processing.py). The FAITHFUL enhancement + downscale chain
# needs only OpenCV/numpy/Pillow (core deps). These extras power the GPU steps:
#   - enhancement engine "esrgan": Real-ESRGAN via spandrel
#   - de-watermark: SDXL-inpaint via diffusers (reconstructs the mark's footprint)
# Install on the GPU image-processing container; the core pipeline does not need them.
#
#   pip install -r stone_pipeline/requirements-imageproc.txt
#
# History: Florence-2 (open-vocab detection) and LaMa (plain inpaint) were both dropped —
# Florence missed the faint logo; LaMa smeared patterned stone. SDXL-inpaint replaces LaMa.
# Runs fp16 on CUDA (fast) / fp32 on MPS/CPU. GPU strongly recommended for a full batch.
